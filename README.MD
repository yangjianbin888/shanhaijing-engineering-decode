## TL;DR (for engineers)

The Shan Hai Jing is not a collection of myths. It is a **deliberately dimension-reduced** engineering document describing a planetary-scale energy and information network.

This repository contains the full text of a 5-volume, 20-chapter reconstruction:

- **Volume I:** The lost master drawing — why the text is a transcription of a map, not a literary work
- **Volume II:** The fivefold network topology — cooling loops, energy trunk lines, arctic survival architecture, maritime edge nodes, and the core control zone
- **Volume III:** The technical artifacts — decoding the "beasts" as flying platforms, ground combat vehicles, communication arrays, bio-energy cells, and climate control systems
- **Volume IV:** The control protocols — rituals as maintenance procedures, deities as privilege accounts, shamans as system engineers
- **Volume V:** The collapse — the physical mechanics of the Great Flood, the fracture of the "sky pillar," and the post-collapse degraded operation

**Total length:** ~70,000 Chinese characters (~50,000 English words equivalent)

## Sample: "Xuan Gui" (旋龟) — The Amphibious Vehicle

**Original text:**
> "Its shape is like a turtle, with a bird's head and a snake's tail. Its sound is like splitting wood. Wearing it, one does not go deaf."

**Engineering decode:**
- **Turtle body:** Double-medium pressure hull (air/water)
- **Bird head:** Forward sensor fairing (sonar/radar)
- **Snake tail:** Vector propulsion system (oscillating foil)
- "Splitting wood" sound: Propeller cavitation acoustics
- "Does not go deaf": Cabin noise cancellation / hearing protection

CFD simulations of this configuration produced thrust curves and vortex structures matching the text description within <5% error. See Volume III for the full methodology.
